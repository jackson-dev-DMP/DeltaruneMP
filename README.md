# DeltaruneMP

**DeltaruneMP** is an unofficial multiplayer project for *Deltarune*. This project aims to bring local and network multiplayer features into the game, allowing players to explore, interact, and test together.

---

## 🚀 Features

* **LAN Multiplayer:** Play together over the same local network.
* **Installer Setup:** Easy setup using the official `DeltaruneMP_Setup.exe` installer.
* **Custom Engine Tweaks:** Built specifically for testing synchronized player movement and interactions.

---

## 🛠️ Installation & Setup

1. Go to the **[Releases](../../releases)** section on the right side of this repository.
2. Download the latest version of `DeltaruneMP_Setup.exe`.
3. Run the installer and follow the on-screen prompts.
4. Launch the game and select your connection options!

---

## 🧪 Notes for Testers

This project is currently in **Beta testing**. If you are testing this build, please keep the following in mind:

* **Focus Area:** Please test basic movement, player connectivity, and stability over your local network (LAN).
* **Known Issues:** Worldwide online multiplayer is currently in extreme testing and will be less worked on until LAN synchronization is fully optimized.
* **Reporting Bugs:** If you encounter crashes, disconnects, or unexpected bugs, please let us know!
